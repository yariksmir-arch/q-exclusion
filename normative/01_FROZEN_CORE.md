# Frozen Core v0.1

## 1. Concrete structural presentation
A formal presentation `K` supplies declared structural content `B_K`. `B_K` is not asserted to be a God’s-eye world object. It is the accepted content of the concrete formalization under analysis.

No privileged foundational formal language is assumed. Graphs, categories, first-order structures, algebras, sheaves, process calculi and other formalisms are metamathematical representations.

## 2. Q-Exclusion / Structural Sufficiency
Given an extension with forgetful map

`U : B_{K+} -> B_K`,

a candidate fact `F : B_{K+} -> Y` belongs to the old theory only if it factors through `U`:

`F = Fbar ∘ U`.

Equivalently:

`U(e1)=U(e2) => F(e1)=F(e2)`.

If not, `F` uses content absent from `B_K`.

Consequences:
- no hidden selector;
- no privileged representative;
- no hidden actual global completion;
- no objective probability unless derived as structure of the empirical signature;
- no absolute identity/order/time unless derived;
- no observer/consciousness primitive;
- no ontic reification of formal automorphisms.

## 3. Concrete arrangements and repertoires
For a chosen sector of `B_K`, let `A_K` denote the represented arrangements/processes/objects under study. This symbol is metamathematical and may be partial/typed.

A repertoire `R` is a concrete collection of represented tests/contexts. `R` is not the set of all possible experiments.

## 4. Contextual empirical equivalence
For compatible `f,g in A_K`, define

`f ~_R g`

iff every represented test context in the declared contextual closure of `R` produces the same finite/declared readout on `f` and `g`.

The closure notion itself must be generated only from actually represented composition operations. If such closure is absent, no congruence is assumed.

## 5. Empirical quotient
Where `~_R` is an equivalence relation, define

`E_R = A_K / ~_R`.

Where `~_R` is also a congruence for represented operations, these operations descend to `E_R`.

## 6. Empirical Descent Principle
A concrete relation or operation is scientist-level meaningful only when it is invariant on empirical equivalence classes in every input and output required for its typing.

For `F : X1 x ... x Xn -> Y`, scientist-level `Fbar` exists only if

`xi ~ xi' for all i => F(x1,...,xn) ~ F(x1',...,xn')`.

## 7. Refinement
If a concrete repertoire is extended `R ⊆ R'`, richer testing may refine equivalence:

`~_{R'} ⊆ ~_R`.

Where quotients exist, there is a canonical coarse map

`pi_{R'R} : E_{R'} -> E_R`.

No inverse limit over all possible repertoires is ontologically postulated.

## 8. Empirical signature
`Sigma_R` denotes `E_R` together with exactly those relations, operations, quantitative assignments and typed structures that have actually descended at repertoire `R`.

`Sigma_R` is the main scientist-level object of the theory.

## 9. Representation humility
A mathematical representation of `Sigma_R` is not additional physical content. If two representations preserve all declared structure of `Sigma_R`, differences not descending back to `Sigma_R` are representational surplus relative to `R`.

## 10. Non-core modules
The following are explicitly non-core unless later proved unavoidable:
- finite-code scaffolding;
- probability/convexity;
- clocks/time;
- localization/spacetime;
- Jordan/operator/Hilbert structure;
- fields;
- symmetry/gauge/particles;
- active lattices;
- higher-order control.

They may be developed as optional structures/recognition modules on `Sigma_R`.
